# Slide 1: Title
## Comparative Performance Analysis of ML Models
**Author:** Research Team

---
# Slide 2: Problem Statement
- High accuracy models often require substantial compute time.
- Decision latency impacts real-time machine learning deployments.
- **Research Question:** How much does ensemble complexity improve performance relative to speed?

---
# Slide 3: Methodology
- Applied Decision Trees, Random Forests, and Gradient Boosting.
- Standard pre-processing with stratified 80/20 train-test split.

---
# Slide 4: Key Results
- **Gradient Boosting:** 92.4% Accuracy (Runtime: 8.5s)
- **Random Forest:** 88.6% Accuracy (Runtime: 3.8s)
- **Decision Tree:** 81.2% Accuracy (Runtime: 1.2s)

---
# Slide 5: Key Takeaways
- Gradient Boosting delivers highest accuracy (+11.2%).
- Random Forest balances speed and precision for real-time systems.
