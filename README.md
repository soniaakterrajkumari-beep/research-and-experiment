# Research Paper: Machine Learning Model Benchmarking

This repository contains the full paper, experimental notebook, slide deck, and visualizations for the comparative study on classification models.

## Repository Directory

- [Research Paper](paper.md)
- [Experimental Methodology](methodology.md)
- [Jupyter Notebook & Data Analysis](notebook.ipynb)
- [Presentation Slides Outline](slides.md)

## Summary
The study compares Decision Trees, Random Forests, and Gradient Boosting on accuracy and execution runtime. Gradient Boosting achieved 92.4% accuracy but required significantly longer training time compared to standard trees.
